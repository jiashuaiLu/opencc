DongCC 发展历程

从初版到 v1.3.0 的进化之路 | 2026-04-25

两个月前，我们发布了 DongCC 的第一个版本。那时候，它只是一个简单的 Claude Code 代理服务管理工具，功能单一，界面朴素。而今天，DongCC 已经成长为一个功能完善、界面精美、支持多平台的桌面应用。这篇文章将带你回顾 DongCC 从 v1.0.0 到 v1.3.0 的完整进化历程。

🚀 v1.0.0：从零到一（2026-03-05）

一切从一个简单的想法开始：让 Claude Code 的使用更简单。

在 v1.0.0 版本中，我们搭建了基础框架，实现了核心功能：

  • 代理服务管理：一键启动/停止代理服务
  • 配置管理：图形化界面配置 API Key 和 Base URL
  • 日志系统：实时查看运行日志
  • 监控统计：基础的 Token 消耗统计
  • 对话历史：查看和管理对话记录

v1.0.0 技术选型

我们选择了 Electron + React + TypeScript 的技术栈，这是桌面应用开发的经典组合。前端使用 Ant Design 5 作为 UI 组件库，数据库采用轻量级的 LowDB，日志系统使用 Winston。

Electron React 18 TypeScript Ant Design 5 LowDB Winston

✨ v1.1.0：焕然一新（2026-03-08）

v1.0.0 发布后，我们收到了很多反馈。用户说："功能不错，但界面有点丑。"于是，我们决定进行一次彻底的设计升级。

v1.1.0 是一次重大的 UI/UX 改版：

  • 全新设计系统：采用极简主义设计，清晰的视觉层次和信息架构
  • 暗黑模式：原生支持深色模式，可跟随系统自动切换
  • MCP 管理：配置和管理 Model Context Protocol 服务器
  • Skills 管理：管理和发现 Claude Code 技能插件
"设计不仅仅是外观，更是功能。好的设计让复杂的事情变得简单。"

🎯 v1.2.0：精益求精（2026-03-10）

在界面升级后，我们开始专注于功能的完善和细节的打磨。

v1.2.0 版本的改进包括：

  • 配置优化：模型配置改为必填项，添加默认值和说明
  • UI 升级：优化 MCP 和 Skills 管理页面样式
  • Skill 管理：移除项目级 Skill 提升功能，符合官方设计
  • 度量看板：修复请求日志字段显示问题
  • 主题优化：非暗黑模式下菜单栏白色背景

🎉 v1.3.0：跨越平台（2026-04-25）

这是 DongCC 发展史上的一个重要里程碑。我们不仅增加了对 Windows 平台的支持，还实现了与京东云 Anthropic 兼容 API 的对接。

v1.3.0 的核心更新：

  • 京东云支持：支持京东云 Anthropic 兼容 API
  • 参数清理：优化代理服务参数清理逻辑，兼容更多云服务商
  • Universal 架构：macOS 版本支持 Intel 和 Apple Silicon 双架构
  • 工具调用修复：修复工具调用 ID 格式验证问题
  • 空内容处理：修复空文本内容处理问题

v1.3.0 架构升级

为了实现跨平台支持，我们对构建配置进行了重大调整。macOS 版本现在采用 Universal 架构，同时包含 x64 和 arm64 两个架构，一个安装包即可支持所有 Mac 设备。

🔧 技术挑战与解决方案

挑战一：代理服务参数兼容

不同的 AI 服务商对请求参数的要求各不相同。例如，京东云要求 tool_use.id 必须符合正则表达式 ^[a-zA-Z0-9_-]+$，而 Claude Code 生成的 ID 可能包含其他字符。

解决方案：我们在代理服务层添加了参数清理逻辑，自动过滤和转换不符合要求的参数。

挑战二：跨平台打包

Electron 应用在不同平台上的打包配置差异很大，特别是 macOS 的签名和公证流程。

解决方案：我们使用 electron-builder 的通用架构配置，通过 "arch": ["x64", "arm64"] 实现一次打包，双架构支持。

挑战三：API 格式适配

京东云的 Responses API 格式与标准 Anthropic API 有很大差异，包括字段命名、数据结构和响应格式。

解决方案：我们实现了灵活的 API 格式转换层，支持 Anthropic、Chat Completions 和 Responses 三种格式的自动转换。

📊 数据见证成长

从 v1.0.0 到 v1.3.0，DongCC 的代码量增长了 3 倍，功能模块从 6 个扩展到 12 个，支持的云平台从 1 个增加到 4 个。

  • 代码行数：从 5,000+ 行增长到 15,000+ 行
  • 功能模块：从 6 个扩展到 12 个
  • 支持平台：从仅 macOS 扩展到 macOS + Windows
  • 支持云服务商：从 1 个增加到 4 个
