功能特性

🚀

代理服务管理

一键启动/停止代理服务，支持多种 API 服务提供商，包括 JoyBuilder、OpenAI、DeepSeek 等

⚙️

配置管理

图形化配置界面，支持多个配置方案，配置导入/导出，轻松管理不同环境

📊

监控统计

Token 消耗统计，请求耗时分析，成功率统计，全面掌握服务运行状态

📝

日志系统

实时运行日志，多级别日志过滤，日志搜索和导出，快速定位问题

💬

对话历史

查看和管理所有对话历史，支持搜索和导出，方便回溯和分析

🔒

安全可靠

本地运行，数据安全可控，支持多种认证方式，保护您的 API Key

系统要求

macOS 版本

  • macOS 10.15 (Catalina) 或更高版本
  • Apple M1/M2/M3 芯片或 Intel 处理器
  • Claude Code CLI 已安装

Windows 版本

  • Windows 10 或 Windows 11
  • 64 位系统
  • 至少 4GB 内存
  • Claude Code CLI 已安装

安装教程

📥

第一步：下载安装

下载 DMG 文件，打开后将 OpenCC.app 拖入 Applications 文件夹

→
⚠️

第二步：允许运行

首次打开时如果提示「无法打开」，点击「取消」

→
🔧

第三步：系统设置

打开「系统设置」→「隐私与安全性」

→
✅

第四步：仍要打开

在安全性设置中找到 OpenCC，点击「仍要打开」即可
